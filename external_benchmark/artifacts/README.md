# external_benchmark/artifacts/

Generated by `python3 -m external_benchmark.ieee_cis_evaluate`. Contains
only aggregate metrics — never raw transaction rows, transaction IDs,
merchant IDs, identity fields, or record-level predictions.

- `latest_ieee_cis_report.json` — the most recent benchmark run's split
  description, selected feature list, threshold-selection grid, and
  held-out-test metrics, plus the required non-claims text.
- `selected_feature_list.json` — the exact numeric/categorical feature
  columns used, written every run.

Both files are entirely separate from `ml/artifacts/` (ClearRisk's own
evaluation report) and are never read by `ml/`, `app/`, or `dashboard/`.
